# Erick-Samuel Franz — Online-Portfolio

Statische Portfolio-Website in HTML, CSS und JavaScript, aufgebaut nach der Bildverteilung und den Kapiteln des bereitgestellten PDF-Portfolios.

## Lokal testen
1. ZIP entpacken und den Ordner in VS Code öffnen.
2. Erweiterung **Live Server** installieren.
3. `index.html` öffnen, Rechtsklick → **Open with Live Server**.
4. Änderungen speichern; der Browser aktualisiert sich automatisch.

## GitHub Pages
1. Ein GitHub-Repository namens `Portfolio` oder `erick-portfolio` erstellen.
2. Den Inhalt dieses Ordners hochladen. `index.html` muss im Repository-Stammverzeichnis liegen.
3. Repository → **Settings → Pages**.
4. **Deploy from a branch** wählen, Branch `main`, Ordner `/(root)`, dann **Save**.
5. Nach dem Deployment wird die öffentliche URL im Pages-Bereich angezeigt.

## Dateien
- `index.html`: Inhalt, Bilderverteilung, Kapitel- und Kontaktlinks
- `style.css`: Design und responsives Layout
- `script.js`: mobile Navigation und Jahreszahl
- `assets/`: Bilder und Blender-Videos

Die Navigationsreiter springen direkt zu den Kapiteln. Instagram-Links führen zu `@kn.erick` und `@kn.erickpiano`.


## Musik & Audio
Im Abschnitt „Musik & Audio“ sind vier Tracks eingebunden. Die nativen HTML-Audioplayer bieten Play/Pause, Zeitleiste und Lautstärkeregelung. Die Dateien liegen im Ordner `assets`.

## Bilder
Die neu bereitgestellten, benannten Bilder wurden in den Ordner `assets` kopiert und im HTML den passenden Kapiteln zugeordnet. Beim Aktualisieren auf GitHub bitte den gesamten Ordner `assets` mit hochladen.
